# نور القرآن — تطبيق أندرويد

مصحف مكتوب (رسم مجمع الملك فهد) مع تظليل الآية أثناء التلاوة، تلاوات كاملة لأشهر القراء، والأربعون النووية مقروءة ومسموعة، وإعدادات شاملة.

## بناء ملف APK — الطريقة الأسهل (بدون تثبيت أي شيء)
1. أنشئ مستودعًا جديدًا على GitHub وارفع محتويات هذا المجلد كما هي (مع مجلد `.github`).
2. افتح تبويب **Actions** — سيبدأ البناء تلقائيًا (حوالي ٥ دقائق).
3. بعد انتهائه افتح عملية البناء ← **Artifacts** ← حمّل `NoorQuran-APK`.
4. داخل الملف المضغوط: `app-release.apk` — انقله للجوال وثبّته (فعّل "التثبيت من مصادر غير معروفة").

## أو عبر Android Studio
افتح المجلد في Android Studio ← Build ← Build APK(s).

## مصادر البيانات
- نص القرآن: Quran.com API (النص العثماني لمجمع الملك فهد)، واحتياطيًا AlQuran.cloud
- التلاوة آية بآية مع التظليل: EveryAyah.com (26 قارئًا)
- التلاوات الكاملة: MP3Quran.net (أكثر من 200 قارئ)
- الأربعون النووية: fawazahmed0/hadith-api
- النطق: محرك TTS العربي في الجوال (Google)

كل ما يُحمَّل يُحفظ محليًا، فيعمل بعد ذلك بدون إنترنت (عدا الصوت).

## تخصيص
- اسم التطبيق: `app/src/main/res/values/strings.xml`
- الأيقونة: `app/src/main/res/drawable/ic_launcher_foreground.xml`
- الواجهة: `app/src/main/assets/www/`
- قبل النشر على Google Play: أنشئ مفتاح توقيع خاص بك بدل مفتاح debug.
